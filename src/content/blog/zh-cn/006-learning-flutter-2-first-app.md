Flutter环境安装好之后，迫不及待的想要尝试一下了吧，下面介绍三种创建Flutter项目的方式。

## 方式一：命令行

1. 创建项目

   ```shell
   flutter create hello_world
   ```

2. 启动一个模拟器，以iOS为例

   ```shell
   open -a Simulator
   ```

3. 运行项目

   ``` shell
   cd hello_world
   fullter run
   ```


## 方式二：Android Studio

1. 下载[Android Studio](https://developer.android.com/studio)

2. 安装Flutter和Dart插件

   ![flutter_plugin](https://tva1.sinaimg.cn/large/006tNbRwgy1gbkogon09nj319w0gc0vj.jpg)

3. Start a new Flutter project

   ![](https://tva1.sinaimg.cn/large/006tNbRwgy1gbkojy4ckxj315k0rkgom.jpg)

4. 启动一个模拟器

   ![](https://tva1.sinaimg.cn/large/006tNbRwgy1gbkon2sbwlj30z40eswi7.jpg)

5. 点击运行按钮启动程序
