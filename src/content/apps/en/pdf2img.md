[PDF2IMG](https://apps.apple.com/us/app/pdf2img/id1236146668) is an iPhone / iPad tool for turning PDF pages into images and merging the ones you pick into a single long picture. Rendering stays on-device — files are not uploaded to our servers.

## What it does

- Convert each PDF page into an image
- Choose which pages to merge into a long picture
- Customize page layout and margins
- Export at 300 DPI print quality

## How to use it

1. Import PDF files into the app
2. Refresh the file list
3. Select the pages you want and merge them into a picture

Requires **iOS 16.0+** (iPadOS 16.0+). Also runs on Apple silicon Macs (macOS 13.0+) and Apple Vision. Get it on the [App Store](https://apps.apple.com/us/app/pdf2img/id1236146668). Getting started is in the [docs](/en/docs/pdf2img/).
