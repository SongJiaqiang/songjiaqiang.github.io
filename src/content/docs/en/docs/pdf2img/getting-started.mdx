Get **PDF2IMG** from the [App Store](https://apps.apple.com/us/app/pdf2img/id1236146668).

## Requirements

**iOS 16.0+** or **iPadOS 16.0+**. It also runs on Apple silicon Macs (macOS 13.0+) and Apple Vision.

## Use

1. Import PDF files into the app
2. Refresh the file list
3. Select the pages you want to convert
4. Merge them into a long picture (or export page by page)

You can adjust layout and margins. Export is 300 DPI. Processing stays on-device — PDFs are not uploaded to our servers.
