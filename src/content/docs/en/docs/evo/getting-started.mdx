## Prerequisites

Install [Flutter](https://docs.flutter.dev/get-started/install). On macOS you also need the Xcode command-line tools; for Android, the Android SDK.

There is a Chinese install note on the blog: [Installing Flutter](/blog/005-learning-flutter-1-install).

## Clone and run

```bash
git clone https://github.com/SongJiaqiang/Evo.git
cd Evo
flutter pub get
flutter run
```

If several devices are connected:

```bash
flutter run -d <deviceId>
```

A physical iOS device needs signing configured in `ios/Runner.xcworkspace`.
