## Requirements

**macOS 14.6+**.

## Install

Download the latest `IconCraft-Installer.dmg` from [GitHub Releases](https://github.com/SongJiaqiang/IconCraft/releases). Open it and drag **IconCraft** into Applications.

## Use

1. Drop in a 1024×1024 master icon
2. Choose your iOS project folder — IconCraft looks for `AppIcon.appiconset`
3. Inspect pixel diffs against the current icon
4. Replace every required size and write `Contents.json`

All processing stays on-device. Nothing is uploaded.
