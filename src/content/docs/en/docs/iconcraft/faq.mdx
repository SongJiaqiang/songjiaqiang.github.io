## Does it upload my icons?

No. Image work runs on-device. There are no network requests and no telemetry.

## Which sizes does it generate?

It follows the [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/app-icons) for iPhone, iPad, and the 1024×1024 App Store marketing icon.

## Can I install it with Homebrew?

A cask is planned. For now, download the dmg from [Releases](https://github.com/SongJiaqiang/IconCraft/releases).
