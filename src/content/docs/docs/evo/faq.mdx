## Evo 和 EvoRadio 有什么区别？

[EvoRadio](https://github.com/SongJiaqiang/EvoRadio) 是 2016 年的 Swift 练习项目。Evo 是 2020 年用 Flutter 重写的版本，目标是更简单的播放流程，并覆盖全面屏机型。

## 还在维护吗？

这是一个学习与实践项目，目前作为归档作品展示。源码仍可在 GitHub 查看。

## 为什么界面像豆瓣 FM？

重写时参考了豆瓣 FM 的左右滑屏和轻量播放体验，用来检验 Flutter 布局和手势。
