在 [App Store](https://apps.apple.com/us/app/pdf2img/id1236146668) 下载 **PDF2IMG**。

## 环境

需要 **iOS 16.0+** 或 **iPadOS 16.0+**。搭载 Apple 芯片的 Mac（macOS 13.0+）和 Apple Vision 也可以运行。

## 使用

1. 把 PDF 文件导入应用
2. 刷新文件列表
3. 选中要转换的页面
4. 合并成一张长图（也可按页导出）

可以调整版面和边距，导出分辨率为 300 DPI。处理在本机完成，PDF 不会上传到我们的服务器。
