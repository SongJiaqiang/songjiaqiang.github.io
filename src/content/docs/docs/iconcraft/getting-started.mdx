源码与安装包：[SongJiaqiang/IconCraft](https://github.com/SongJiaqiang/IconCraft)。

## 环境

需要 **macOS 14.6+**。

## 安装

从 [GitHub Releases](https://github.com/SongJiaqiang/IconCraft/releases) 下载最新的 `IconCraft-Installer.dmg`，打开后把 **IconCraft** 拖进「应用程序」。

## 使用

1. 拖入一张 1024×1024 的主图标
2. 选择 iOS 工程目录，IconCraft 会查找 `AppIcon.appiconset`
3. 查看与当前图标的像素差异
4. 一键替换全部规格，并写入 `Contents.json`

处理全程在本机完成，不会上传素材。
